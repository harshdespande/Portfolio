Perfume Recommendation System ↗

An AI-powered fragrance recommendation engine using natural-language interaction via Llama 3 through the Chat-Groq API. Delivers personalized suggestions by factoring in body chemistry and lifestyle data, with MySQL as the structured backend.
  • Natural-language chat interface powered by Llama 3 LLM
  • User preference logic incorporating body chemistry & lifestyle factors
  • MySQL backend for structured fragrance metadata storage & retrieval
  • End-to-end data pipeline: input → LLM reasoning → DB query → output
